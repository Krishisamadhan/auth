Important

Mujhe sirf code copy-paste nahi karna hai. Mujhe samajhna hai ki Laravel production projects mein architecture aise kyu banaya jata hai.

Ab hum sabse pehle Activity ke authorization ko Policy mein convert karenge, kyunki abhi mere controller mein manually:

if ($activity->user_id !== auth()->id()) {
    return view('activity.not-found');
}


likha hua hai.

Pehle mujhe Laravel Policy properly samjhao, phir mere Activity model/controller/routes ke according implement karwao.

Ek time par sirf ek major concept karna hai.
